# C Programming Fundamentals

A comprehensive collection of C programming exercises, algorithmic problem solutions, and practical implementations developed during university coursework in **Introduction to Computer Studies (ICS)** and **Structured Programming Language (SPL)** (2024).

This repository documents the foundational transition into low-level systems programming, procedural logic, memory management, and structured software design.

---

## 📌 Repository Overview

The repository covers low-level programming concepts from basic syntax to advanced pointers, recursion, file input/output, and custom data structures. It also features practical console projects and university lab assessments.

### Core Competencies Demonstrated
* **Procedural Logic & Control Flow:** Conditional execution, nested looping, and modular procedural paradigms.
* **Array & Matrix Manipulations:** Multi-dimensional transformations, matrix arithmetic, and vector processing.
* **Manual Memory & Pointers:** Direct memory address manipulation, pointer arithmetic, pass-by-reference semantics, and dynamic allocations.
* **String Operations:** Buffer handling, custom string manipulations, and boundary protection without over-reliance on abstraction.
* **Structured Data:** Custom composite types (`struct`), record encapsulation, and data aggregation.
* **Persistent Storage (File I/O):** Reading, writing, parsing, and persisting application state to disk using C file streams.
* **Recursive Problem Solving:** Divide-and-conquer logic, stack tracing, and algorithmic state exploration.
